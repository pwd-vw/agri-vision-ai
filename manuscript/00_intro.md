# บทนำ: จากพริกหนึ่งเม็ดสู่ AI ที่ตัดเกรดได้เอง

## เปิดเรื่อง

ผู้ปลูกและผู้รวบรวมพริก Habanero ต้องคัดเกรดด้วยสายตา ซึ่งช้า ไม่สม่ำเสมอ และขึ้นกับคนคัด
ถ้ากล้องตัวเล็กราคาไม่กี่พันบาทช่วยคัดพริกได้ จะเป็นอย่างไร?

พริก Habanero เป็นแค่ตัวอย่าง — ทักษะที่ได้จากเล่มนี้ใช้กับงานตรวจสอบคุณภาพอะไรก็ได้ที่แยกด้วยภาพ

## ภาพรวมสิ่งที่จะเรียน

วงจร Vision AI ทั้งเล่มมี 4 ขั้นตอน: **ถ่ายภาพ → Annotate → Train → Deploy**

ศัพท์พื้นฐาน:
- **Computer Vision** — การให้คอมพิวเตอร์ "เข้าใจ" ภาพ
- **Object Detection** — หาตำแหน่งและระบุชนิดของวัตถุในภาพ (ในเล่มนี้คือแต่ละเม็ดพริก)
- **Edge AI** — รันโมเดลบนอุปกรณ์หน้างาน (Raspberry Pi 5) แทนที่จะส่งภาพขึ้นคลาวด์ — เร็วกว่า
  ถูกกว่า และใช้งานได้แม้ไม่มีอินเทอร์เน็ต

## โปรเจกต์ Capstone: ระบบตรวจคุณภาพพริก Habanero

- **ตัวโมเดล:** ตรวจจับพริกแต่ละเม็ดในภาพ (Object Detection) แล้วระบุคลาสคุณภาพ
- **คลาสเริ่มต้น** (ดู `docs/labeling-guide.md` สำหรับเกณฑ์ฉบับเต็ม):
  - `graded` — สุกได้เกรด (สีส้ม/แดงสม่ำเสมอ ผิวเรียบ)
  - `unripe` — ดิบ/ยังไม่สุก (เขียว)
  - `defective` — ตำหนิ (จุดดำ เน่า รา ช้ำ เหี่ยว)
- **ผลลัพธ์บน Pi 5:** กล้องส่องพริกบนสายพานหรือถาด แล้วแสดงผลแบบ real-time พร้อมนับจำนวนแต่ละเกรด
- **ต่อยอด** (ภาคผนวกท้ายเล่ม): ส่งสรุปเข้า LINE หรือสั่ง GPIO ไปดันพริกคนละถัง

## เป้าหมายการเรียนรู้

เมื่ออ่านจบ ผู้อ่านสามารถ:

1. วางแผนและถ่ายชุดภาพที่มีคุณภาพสำหรับงาน Vision
2. ทำ annotation และสร้าง dataset เวอร์ชันบน Roboflow ได้
3. Train และประเมินโมเดลบน Colab ได้ พร้อมอ่านผลเป็น
4. Export และรันโมเดลบน Raspberry Pi 5 ได้จริง
5. ปรับปรุงโมเดลรอบสองจากข้อผิดพลาดที่พบ

## เกณฑ์ความสำเร็จของ Capstone

> ตัวเลขด้านล่างเป็นตัวอย่าง — ต้องยืนยันด้วยการทดสอบจริงก่อนพิมพ์ แล้วอัปเดตที่นี่

- mAP50 ผ่านเกณฑ์ที่กำหนด (เช่น ≥ 0.85)
- รันบน Pi 5 ได้ที่ FPS ใช้งานได้จริง (กำหนดตัวเลขหลังวัดจริงใน `results/fps_comparison.md`)
- ทดสอบกับพริกล็อตใหม่ที่ไม่เคยอยู่ใน dataset (held-out lot) แล้วผลไม่ตก

## ใครควรอ่าน / พื้นฐานที่ต้องมี

ไม่ต้องมีพื้นฐาน AI มาก่อน ขอแค่ใช้คอมพิวเตอร์และพิมพ์คำสั่งง่าย ๆ ได้

อุปกรณ์ที่ต้องมี: Raspberry Pi 5, กล้อง, แหล่งแสง, พริกตัวอย่าง (ดูงบประมาณโดยประมาณใน
ภาคผนวก — ยังไม่ระบุ)

## แผนที่เล่ม

| บท | สิ่งที่ทำ | Checkpoint |
|---|---|---|
| 1. การเตรียมรูปภาพ | ถ่ายภาพตาม `docs/capture-protocol.md` | ภาพครบตามจำนวน ไม่ซ้ำ ไม่เบลอ แบ่งตามล็อต |
| 2. Annotation บน Roboflow | Label ตาม `docs/labeling-guide.md` สร้าง dataset v1 | ผ่าน Health Check, label สม่ำเสมอ |
| 3. Train บน Colab | Train, ประเมิน, วนแก้ | ได้โมเดลผ่านเกณฑ์ + รายงานผล |
| 4. Deploy บน Pi 5 | Export, รันจริง, วัด FPS | มีตัวเลข FPS + ทดสอบกับล็อตใหม่ |

ไฟล์ประกอบของเล่มนี้ทั้งหมดอยู่ใน repo เดียวกัน: dataset ตัวอย่าง (`sample_data/`), Colab
notebooks (`notebooks/`), และโค้ดสำหรับ Pi (`pi/`) — ดูวิธีรับอัปเดตใน README หลักของ repo

## ระบบวัดผลและ Recap ท้ายทุกบท

ทุกบทใช้โครงเดียวกัน:

- **Key Takeaways** — สรุป 3–5 ข้อ
- **Knowledge Check** — คำถามทบทวน 5 ข้อ พร้อมเฉลยท้ายเล่ม
- **Checkpoint** — ชิ้นงานที่ต้องได้ก่อนไปบทถัดไป
- **Self-Score** — เกณฑ์ผ่าน/ต้องแก้ ที่ตรวจเองได้ด้วยตัวเลข
- **Common Pitfalls** — ข้อผิดพลาดที่พบบ่อยของบทนั้น (เก็บจาก error log จริงระหว่างทำ)

**Capstone Final:** เช็กลิสต์ผ่าน/ไม่ผ่านรวม 10 ข้อ ผู้อ่านให้คะแนนตัวเองและรู้ว่าควรย้อนไปทบทวนบทไหน
